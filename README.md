# customer-churn-analysis
Customer churn analysis using SQL, Python, Excel, and Power BI to identify key factors affecting customer retention and visualize churn patterns through interactive dashboards.
## Tools
- SQL
- Python
- Excel
- Power BI

## What I did
- Data cleaning using SQL and Excel
- Data analysis using SQL queries
- Data visualization using Power BI and Python charts
- Extracted key insights from customer churn data

## Key Results
- Identified high-risk customer segments with higher churn rate
- Found that certain customer groups are more likely to leave the service
- Discovered key factors influencing churn such as contract type and payment behavior
- Created interactive dashboards to visualize churn patterns
